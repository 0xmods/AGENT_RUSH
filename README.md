# AGENT RUSH – Project Overview

AGENT RUSH is a Web3 ecosystem developed on the BNB Chain that brings together an NFT collection, a native token economy, and AI agents. The primary goal of the project is to elevate NFT ownership beyond merely acquiring digital collectibles by integrating it with community participation, rewards, and AI-supported Web3 experiences.

## How the System Works

The starting point of the project is the Genesis collection, consisting of 8,000 NFTs in total. The collection features 100 different character designs, with a maximum of 80 units minted per character.

- 800 NFTs will be minted for free
- 7,200 NFTs will be minted for 0.001 BNB each
- Each wallet can acquire a maximum of 10 NFTs
- Only one NFT per wallet can be free

With every successful NFT minting transaction, 50,000 $RUSH will be instantly sent to the NFT owner's wallet. Thus, all Genesis NFT owners, whether they mint for free or for a fee, will benefit from the same token reward.

## $RUSH Token Economy

$RUSH is the native token of the AGENT RUSH ecosystem. Its maximum supply is planned to be 1 billion. In addition to Genesis NFT rewards, the token is designed for future use in community quests, seasonal events, competitions, exclusive features, and in-ecosystem participation mechanisms.

A designated portion of the revenue generated from NFT sales will be allocated for $RUSH buybacks. It is planned that a portion of the repurchased tokens will be burned, while the remainder will be used for community rewards. This aims to establish a connection between the NFT economy and the token economy.

## AI Agents

One of the key features of AGENT RUSH is that it is built on interaction with AI agents. Users will be able to access the system via their wallets or supported Agent IDs and request AI agents to prepare NFT minting transactions and perform necessary checks.

Through the AI Mint Prompt system, users will be able to create ready-made commands for their AI agents. Before transactions are executed, the wallet, network, minting rights, price, and NFT eligibility will be checked; the signature and transaction approval will always remain under the user's control.

## Future Goals

Following the Genesis NFT and $RUSH token infrastructure, the ecosystem aims to expand with the following features:

- Community quests and reward system
- Exclusive events and competitions for NFT holders
- Leaderboard and seasonal competition
- Advanced interaction with AI agents
- Expansion of token use cases
- New NFT collections and ecosystem applications

The vision of AGENT RUSH is to bring together NFT ownership, community economy, and AI agents within a single Web3 ecosystem, creating a platform where users are not just collectors but active participants in the ecosystem's development.

> Note: The future features and economic mechanisms outlined in the project are currently in the development and approval process. Token rewards or the buyback mechanism do not offer any guarantee of a price increase or financial return.
